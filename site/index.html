Reproducible workflow

Designed to make claims inspectable.

  1. Prepare. Discover A-Z folders, record SHA-256 and dHash values, and preserve source test partitions.
  2. Train. Use a compact CNN with seeded augmentation, early stopping, and metadata-rich checkpoints.
  3. Evaluate. Recheck source bytes, reject exact cross-split duplicates, and report per-class results.
  4. Inspect. Run the CLI or optional local upload/webcam demo with the same preprocessing and class map.

Run it locally

No account, payment, or hosted runtime required.
